How the daily QR code works

  • Each person gets a new QR code every day. The code is issued by the Google Sheets backend and expires at the end of the school day.
  • An old daily code is rejected after its date expires. The scanner also records the Google account used by the scanning station for audit purposes.
  • The same daily code can be scanned for check-in and check-out; the system decides the next action automatically.
  • Student records require an institutional school email; visitors use a personal email. Attendance is written to Google Sheets, which can be downloaded as Excel (.xlsx).
